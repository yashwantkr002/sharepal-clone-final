# SharePal Kolkata Gaming Gadgets Clone

React + Vite recreation of the SharePal Kolkata gaming gadgets rental experience.

## Styling

The entire UI is built with Tailwind utility classes. There is **no custom CSS stylesheet** in `src/`.

For this assignment build, Tailwind is loaded through the official browser CDN in `index.html`, so the project stays completely free of handwritten CSS files.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Product cards use `src/data/product-list.json`.
- Search, category filters, sorting, brand filters, wishlist, rental dates, login modal, location modal, FAQ accordion and rental bag interactions are implemented.
- The layout is responsive for desktop, tablet and mobile.
